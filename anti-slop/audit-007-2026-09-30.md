# Audit 007: Phase 0 end gate (accessibility pass + R-35 click-through) · 2026-09-30

antislop active: after (project default).

**Scope:** Phase 0 main flows running in the dev stack (`http://localhost:8080`): `/`, `/dev/components`,
`/dev/layouts/{public,app,admin}`, `/dev/media`. Desktop (1024×768) and mobile (375×812). Dark
theme only (owner decision in `DESIGN.md`, no toggle ships). P0-09 staging checks are not part of
this gate; they stay with P0-09.

**Result:** 2 findings (both HIGH, R-26), both in the dev-only component gallery. Every other
element passed.

## Findings

1. **HIGH · R-26 / R-35** `src/resources/js/Pages/Dev/Components.vue:171`. The "Removable" pill's
   `×` button does nothing when clicked: `UiPill` emits `remove`, but the gallery has no handler, so the
   pill stays. **Fix:** give the pill `v-if="showRemovable"` with `@remove="showRemovable = false"`
   and a "Reset" link, so the specimen shows the removal behaviour.
2. **HIGH · R-26** `src/resources/js/Pages/Dev/Components.vue:104, 107–115, 292`. The button specimens
   (15 variant×size, Close icon, Block) and the empty-state "Primary action" look interactive, but a
   click has no visible outcome. **Fix:** have each enabled specimen call
   `push('<variant> <size> clicked')`, so a click shows a toast and the specimens double as a
   click-handler check.
