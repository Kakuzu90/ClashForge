## Findings

1. **Flash message phrasing** (Low)
   - **File:** src/app/Http/Controllers/Admin/DisputeController.php:72
   - **Rule:** R-36 (Copywriting clarity)
   - **Reason:** The flash message format `$request->decision()->label().': done.'` produces awkward phrasing: "Transfer to the claimant: done." and "Deny the claim: done." The label is already action-oriented; the ": done." suffix reads as redundant and stiff.
   - **Priority:** LOW (Quality Lock)
   - **Fix:** Rephrase to use the decision's core action alone, or restructure messages to read more naturally: "Transfer complete" or use a simpler message pattern like "Decision recorded."

2. **Blocked reason message clarity** (Low)
   - **File:** src/app/Domain/PlayerAccounts/Services/DisputeReviewService.php:224
   - **Rule:** R-36 (Copywriting clarity)
   - **Reason:** The message "Needs a super admin: an admin is part of this dispute." uses a colon to connect two separate ideas, making it harder to parse. The lead ("Needs") is also passive phrasing.
   - **Priority:** LOW (Quality Lock)
   - **Fix:** Rephrase to "An admin is a party to this dispute, so only a super admin can decide it." or similar, which makes the cause-and-effect relationship clearer.
